The first release of **Pack Filter**. Drop in your Etterna song packs, choose how strict to be, and download a filtered `.zip` of each pack with the lewd cover art censored. Your original packs are never modified.

## Download

| System | File |
|---|---|
| Windows 10/11 (64-bit) | `PackFilter-1.0.0-windows-x64.zip` |
| macOS, Apple Silicon (M1 and later) | `PackFilter-1.0.0-macos-arm64.dmg` |
| macOS, Intel | `PackFilter-1.0.0-macos-x64.dmg` |
| Linux (64-bit) | `PackFilter-1.0.0-linux-x64.tar.gz` |

The `.zip` files for macOS contain the same app as the `.dmg`. `SHA256SUMS.txt` lists checksums for every file.

**First launch:** the app isn't code-signed yet, so your system will warn you once.
- **Windows:** unzip, run `PackFilter.exe`, then click **More info → Run anyway**.
- **macOS:** drag the app to Applications and open it. When macOS blocks it, go to **System Settings → Privacy & Security**, scroll down, and click **Open Anyway**. (On macOS 14 and older you can instead right-click the app → **Open**.) If macOS says the app "is damaged", run `xattr -dr com.apple.quarantine "/Applications/Pack Filter.app"` in Terminal.
- **Linux:** extract, run `PackFilter/PackFilter`. Optionally run `PackFilter/install.sh` to add it to your app menu.

## What it does

- **Drag and drop** pack folders, your whole Songs folder, or downloaded `.zip` packs.
- Checks every jacket, banner, background, CD title and pack banner with the `anime_dbrating` model. It runs on your computer, works offline, and handles about 1,000 images in 5 seconds.
- **Choose what gets censored:**
  - **Strict:** also hides suggestive covers.
  - **Balanced:** hides sexual covers and anything explicit.
  - **Explicit only:** hides only hentai.
  - **Custom:** a strictness slider and per-image-type toggles.
- **Override any image** with Censor / Keep.
- **Censor styles:** heavy blur, pixelate, solid color, or your own image, with an optional "CENSORED" label. Image sizes and formats stay the same, so Etterna loads them normally.
- **Previews of possibly-lewd covers stay blurred** in the app unless you choose to reveal them.
- **Download** saves one `<Pack> (filtered).zip` per pack to your Downloads folder, or a folder you pick. Extract the zips into Etterna's `Songs` folder to play them.
- Works with Etterna/StepMania/ITG packs, plus osu!, Quaver, K-Shoot and BMS folders.
- Includes a command line for scripting: `PackFilter scan|export|apply|restore`.

## Known limitations

- The model gives a rough estimate. Use Censor / Keep on single images for anything it gets wrong.
- Only `.zip` packs can be added directly. Extract `.rar` and `.7z` packs first and add the folder.
- If Etterna still shows old covers after you install filtered packs, restart it or delete its `Cache` folder.
