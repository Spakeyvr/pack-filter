Pack Filter 1.1.0 can use your GPU on Windows, has a cleaner interface that holds up at any display scaling, and no longer writes "CENSORED" on images.

## Download

| System | File |
|---|---|
| Windows 10/11 (64-bit) | `PackFilter-1.1.0-windows-x64.zip` |
| macOS, Apple Silicon (M1 and later) | `PackFilter-1.1.0-macos-arm64.dmg` |
| macOS, Intel | `PackFilter-1.1.0-macos-x64.dmg` |
| Linux (64-bit) | `PackFilter-1.1.0-linux-x64.tar.gz` |

The `.zip` files for macOS contain the same app as the `.dmg`. `SHA256SUMS.txt` lists checksums for every file.

**First launch:** the app isn't code-signed yet, so your system will warn you once.
- **Windows:** unzip, run `PackFilter.exe`, then click **More info → Run anyway**.
- **macOS:** drag the app to Applications and open it. When macOS blocks it, go to **System Settings → Privacy & Security**, scroll down, and click **Open Anyway**. (On macOS 14 and older you can instead right-click the app → **Open**.) If macOS says the app "is damaged", run `xattr -dr com.apple.quarantine "/Applications/Pack Filter.app"` in Terminal.
- **Linux:** extract, run `PackFilter/PackFilter`. Optionally run `PackFilter/install.sh` to add it to your app menu.

## What's new

### GPU support on Windows
- Scanning now runs on your graphics card through DirectML. It works with any DirectX 12 GPU (NVIDIA, AMD, Intel) and needs no CUDA install.
- Before using the GPU, the app checks that it gives the same scores as the CPU and that it's actually faster. If either check fails, it uses the CPU.
- The status bar shows whether the GPU or CPU is in use. Hover over it to see why.
- You can turn GPU use off under **Detection → Use the GPU when it's faster**.
- Macs keep using the CPU: Apple's CoreML backend was slower and gave wrong scores for these models.

### Interface
- Nothing overlaps anymore on small windows or at 125–200% display scaling. Everything is sized from your system font, and buttons always fit their labels.
- The window opens sized to your screen and fits a 1080p display at 150% scaling.
- New plainer look: neutral grays with your system's accent color, simpler settings, and a new icon.
- Search moved to the toolbar, and empty tabs are hidden.

### Censoring
- Covers no longer have a "CENSORED" label added. The blur speaks for itself.
- The default blur is stronger, and GIF covers stay fully hidden after saving. Previously, saving as GIF could bring back enough detail for the model to rate a blurred cover as lewd.
- The blur and pixelate strength slider now starts at 30. Below that, shapes could still be made out.

### Command line
- `export` and `scan` report whether they ran on the GPU or CPU. Use `--cpu` to skip the GPU.
